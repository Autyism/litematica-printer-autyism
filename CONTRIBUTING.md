# Contributing to Litematica Printer Autyism Edition

**Please report any bugs so we can fix it accordingly!**

## How to report a bug
- Check **Issues** tab to see if the bug has already been reported.
- If not, open a new issue and include:
  - A clear title.
  - The steps that lead to the problem.
  - Your environment details.

## How to suggest something
- Open an issue and write about what you want to see.
- Explain why it would be useful.

## Pull request
1. Fork the repository and clone it (your own personal fork).
```
git clone https://github.com/...
```
3. Create a new branch for your changes
```
cd YOUR-REPOSITORY-NAME
git checkout -b my_branch
```
3. Make your changes.
4. Run tests to make sure nothing is broken.
5. Commit your changes and push to your fork.
6. Open a **Pull Request** against our `master` branch.
   
**Also report typos and grammatical errors!**
